## SQL Joins

SQL Joins are used to combine rows from two or more tables based on related columns. Here are the main types of joins:

### 1. **INNER JOIN**
Returns only the rows that have matching values in both tables.

<img src="https://github.com/user-attachments/assets/0310d660-0ade-425c-95e8-dd8789db6d4d" alt="Inner Join Diagram" width="400"/>

### 2. **LEFT JOIN (LEFT OUTER JOIN)**
Returns all rows from the left table and matching rows from the right table.

<img src="https://github.com/user-attachments/assets/4f05b9b2-2460-402e-b336-6d582214e50e" alt="Left Join Diagram" width="400"/>

### 3. **RIGHT JOIN (RIGHT OUTER JOIN)**
Returns all rows from the right table and matching rows from the left table.

<img src="https://github.com/user-attachments/assets/568f9d0f-3bce-4240-b5f4-0721d4137069" alt="Right Join Diagram" width="400"/>

### 4. **FULL OUTER JOIN**
Returns all rows from both tables, with NULL values where there are no matches.

<img src="https://github.com/user-attachments/assets/fe3a48e5-7311-427b-bad2-065cf71305b1" alt="Full Outer Join Diagram" width="400"/>
